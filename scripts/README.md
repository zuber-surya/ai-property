# Scripts Directory

This directory contains utility scripts for the PropVista CRM project.

## Available Scripts

### `github-issue-generator.sh`
Generates GitHub issue templates based on the sprint backlog and development plan.

**Usage:**
```bash
./scripts/github-issue-generator.sh
```

This script outputs issue templates that can be copied into GitHub or used with the GitHub CLI once authentication is configured.

**Note:** This script does not actually create issues on GitHub - it generates the content that can be used to create issues manually or via the GitHub CLI/API.

### Other Scripts
- `check_drift.py` - Checks for documentation drift (see `.claude/rules/devos.md`)
- `gen_tokens.py` - Generates frontend design tokens from DESIGN.md

## GitHub Setup

Once GitHub authentication is configured for the MCP server or GitHub CLI, you can:

1. Create a GitHub Project (beta) using the structure in `GITHUB_PROJECT_SETUP.md`
2. Use the GitHub CLI to create issues from the generated templates:
   ```bash
   gh issue create --repo zuber-surya/ai-property --title "Issue Title" --body "Issue body" --label "label1,label2"
   ```

3. Or create issues manually through the GitHub web interface using the templates generated by this script.

## Prerequisites for GitHub Integration

To use GitHub CLI (`gh`) with this repository:
1. Install GitHub CLI: https://cli.github.com/
2. Authenticate: `gh auth login`
3. Ensure you have permission to create issues in the zuber-surya/ai-property repository

For the MCP GitHub server to work, you need to:
1. Set up a GitHub Personal Access Token with appropriate permissions
2. Configure it as a secret for the MCP server
